# 테넌트 관리자 사용자 매뉴얼

> **대상:** 사업체(테넌트) 관리자 — 내 홈페이지를 직접 관리하는 고객
> **접속:** `https://admin.{도메인}/login` 또는 내 홈페이지 `https://{도메인}/{내주소}/login`
> **로컬 개발:** `http://localhost:3001`

---

## 1. 로그인 / 로그아웃

1. **관리자 페이지**(`admin.{도메인}`) 또는 **내 홈페이지의 로그인**에서 접속합니다.
   두 곳 모두 **같은 계정**으로 로그인되며, 로그인 상태는 공유됩니다.
2. **이메일 + 비밀번호** 입력 → 로그인
3. 로그인 후 **대시보드**로 이동합니다.
4. 우측 상단(또는 사이드바)에서 **로그아웃**.

> 계정은 운영사가 생성해 전달합니다(이메일 + 초기 비밀번호).

## 2. 화면 구성 (사이드바 메뉴)

| 메뉴 | 경로 | 설명 |
|---|---|---|
| **대시보드** | 홈 | 방문자·문의 요약 |
| **콘텐츠 편집** | 섹션 관리 | 홈페이지 내용 편집 |
| **SNS 설정** | 소셜 채널 | 카카오·인스타 등 링크 |
| **게시판 관리** | 눌러서 펼침: 게시판 목록 · 게시판 생성 · 전체 글 | 글 쓰기·수정·공개, 게시판 추가, 전체 글 일괄 처리 |
| **문의 관리** | 고객 문의 | 접수·처리 |
| **SEO 설정** | 검색 최적화 | 메타 정보·사이트맵 |
| **템플릿** | 디자인 | 홈페이지 템플릿 선택 |
| **분석** | 방문자 분석 | 방문 통계 |
| **요금제** | 결제 | 플랜·결제 관리 |
| **내 홈페이지 바로가기** | — | 실제 홈페이지 새 탭 열기 |

> ⚠️ 일부 메뉴(콘텐츠 편집·SEO·템플릿·분석 등)는 **요금제/기능 설정에 따라 보이지 않을 수 있습니다.**
> 필요한 기능이 안 보이면 요금제 업그레이드 또는 운영사에 문의하세요.

## 4. 콘텐츠 편집 (핵심)

![콘텐츠 편집 — 섹션 관리](images/ad-02-content.png)

홈페이지에 표시되는 **섹션**들을 관리합니다.

### 4-1. 섹션이란?
홈페이지를 구성하는 블록입니다. 유형:
- **메인 배너**(Hero) · **소개**(Intro) · **서비스/진료안내**(Services)
- **갤러리**(사진) · **오시는 길/지도**(Map) · **문의**(Contact)

### 4-2. 편집 방법
1. **콘텐츠 편집** 메뉴 → **섹션 관리** 목록
2. 편집할 섹션 선택 → 폼에서 내용 입력
   - **기본 설정** / **모바일 설정** 탭으로 PC·모바일 각각 조정
   - 이미지 업로드, 제목·문구 입력 (글자 수 제한 표시됨)
3. 저장하면 홈페이지에 **즉시 반영**됩니다.
4. 섹션 **표시/숨기기**, **순서 변경**으로 홈페이지 구성을 바꿀 수 있습니다.

### 4-3. 두 가지 편집 방식 (결과는 동일)
| 방식 | 위치 | 특징 |
|---|---|---|
| **폼 편집** | 관리자 페이지 → 콘텐츠 편집 | 항목별 입력 |
| **인라인 편집** | 내 홈페이지에서 ✏️ **편집 모드** | 화면에서 바로 클릭 수정 |

> 인라인 편집: 로그인 상태로 내 홈페이지 접속 → 우측 하단 **편집 모드** 버튼 → 텍스트/이미지를 화면에서 직접 클릭해 수정 → 저장. 어디서 고치든 결과는 같습니다.

### 4-4. 공지 글 쓰기 (게시판 관리)

1. **게시판 관리 → 공지사항 → 글쓰기**. 로그인한 채 홈페이지 공지 페이지의 **글쓰기** 버튼으로도 들어옵니다.
2. 제목을 쓰고 **문단 · 목록 · 사진 추가** 로 내용을 쌓습니다. `**이렇게**` 감싼 글자는 굵게 보입니다.
3. **임시저장** 은 홈페이지에 보이지 않고, **공개하기** 를 누르면 공지 페이지와 메인 최신 공지에 바로 나옵니다.

- 처음 글을 공개하면 샘플 공지는 자동으로 사라집니다. 먼저 치우려면 **샘플 글 지우기**.
- 지운 글은 목록의 상태를 **휴지통** 으로 바꿔 복원할 수 있습니다.
- 공지 페이지가 없는 템플릿에서는 공지를 쓸 수 없습니다.

**전체 글:** 게시판 관리 → **전체 글**. 여러 게시판의 글을 게시판 · 상태 · 제목으로 찾고, 골라서 한 번에 공개 · 비공개 · 휴지통으로 옮기거나 복원합니다.

**게시판 상세:** 목록에서 게시판을 누르면 탭이 나옵니다. **글 관리** · **기본 정보**(이름 · 설명 · 검색 노출 · 복제 · 삭제) · **필드 관리** · **카테고리** · **권한**(이 셋은 새 게시판만) · **게시판 디자인**(유형 · 표시 · 정렬) · **홈페이지 연결**(주소 · 사용 여부 · 상단 메뉴 표시).

**글쓰기 편집기:** 워드처럼 한 칸에 이어서 씁니다. 위쪽 버튼으로 제목, 굵게, 글자 색, 정렬, 목록, 인용, 링크, 사진, 표를 넣습니다.

**필드 관리:** 제목 · 내용 말고 더 받을 칸(별점, 방문 날짜, 연락처, 이메일, 링크 등)을 게시판당 20개까지 만듭니다. 기본값을 정하면 새 글에 미리 채워지고, **글 목록에 표시** 를 켜면 글 관리 목록에서 값을 바로 볼 수 있습니다. 글쓰기 화면에 바로 나타납니다. 값이 있는 칸은 유형을 바꿀 수 없고, 칸을 삭제해도 글의 값은 남아 복원할 수 있습니다. 필수 칸은 글을 처음 공개할 때 검사합니다. 값은 홈페이지 글 상세에 제목 아래로 보이고, **홈페이지에 표시** 를 끄면 관리자 화면에서만 씁니다. 로그인한 채 홈페이지 글을 보면 **수정** 버튼으로 바로 고칠 수 있습니다.

**게시판 디자인:** 게시판을 열고 **게시판 디자인** 탭에서 목록형 · 갤러리형 · FAQ형 · 카드형을 고릅니다. 유형마다 한 줄 개수, 사진 비율, 작성일 · 요약 표시, FAQ 펼침 방식을 정하고, 기본 정렬(최신 · 오래된 · 제목)과 페이지당 글 수도 여기서 고릅니다. 저장하면 바로 반영되고, 유형을 바꿔도 글은 지워지지 않습니다. 카드형에는 필드 관리에서 **글 목록에 표시** 를 켠 칸의 값도 나옵니다.

**카테고리:** 게시판을 열고 **카테고리** 탭에서 분류(예: 공지 · 이벤트 · 채용)를 게시판당 30개까지 만듭니다. 글쓰기 화면에서 글마다 분류를 고르면, 홈페이지 글 목록 위에 **전체** 와 분류 탭이 생겨 방문자가 분류별로 볼 수 있습니다. 끌거나 화살표로 순서를 바꾸고, 눈 아이콘으로 홈페이지 탭에서 숨길 수 있습니다(숨겨도 글은 **전체** 에 그대로 보입니다). 분류를 삭제할 때 글이 있으면 옮길 분류를 고릅니다. 글 관리 목록에서도 분류로 걸러 볼 수 있습니다.

**권한:** 게시판을 열고 **권한** 탭에서 글을 **누구나** 읽을지, 로그인한 **회원만** 읽을지 고릅니다. 회원만으로 하면 게시판은 상단 메뉴에 그대로 보이고, 로그인하지 않은 방문자에게는 로그인 안내가 나옵니다. 이 게시판의 글은 검색 결과와 사이트맵에 나오지 않습니다. 방문자 회원 기능이 꺼져 있으면 회원만을 고를 수 없습니다.

**회원 글쓰기:** **권한** 탭의 글쓰기를 **회원도**로 바꾸면 로그인한 방문자 회원이 홈페이지 목록의 **글쓰기** 버튼으로 글을 씁니다(제목 · 내용 · 카테고리). 글은 바로 공개되고, 회원은 자기 글만 고치거나 지울 수 있습니다. 한 회원은 1시간에 10개까지 씁니다. 글 관리 목록에는 **회원 작성 · 이름**이 붙고, 관리자가 비공개로 바꾸거나 지울 수 있습니다. 병원 업종, 회원 기능이 꺼진 사업체, 필수 칸이 있는 게시판은 회원 글쓰기를 켤 수 없고, 켠 뒤에는 필수 칸을 만들 수 없습니다.

**검색 노출:** 새 게시판은 **기본 정보** 탭에서 검색 제목 · 설명을 정하고, **검색 결과에 표시** 를 끄면 게시판과 글이 검색 대상과 사이트맵에서 빠집니다 (주소로는 열립니다).

**게시판 추가 (STANDARD 5개, PREMIUM 제한 없음):** 게시판 관리 → **게시판 생성** (또는 목록의 **게시판 추가**) → 이름 · 유형 · 사용 여부 선택. 만들 때 **상단 메뉴에 추가** 를 켜 두면 홈페이지 메뉴에 바로 나옵니다 (이름 · 순서 · 숨기기는 공통 설정의 상단 메뉴). 설정 화면에서 이름을 바꾸거나 복제(글은 제외, 복제본은 메뉴에 넣지 않음)하고, 지운 게시판은 **휴지통** 에서 복원합니다. 주소를 바꾸면 이전 주소는 열리지 않습니다. 테마형 템플릿에서는 메뉴가 섹션 뒤에 붙고, 공지 전용 페이지가 없어 공지 글은 홈페이지에 보이지 않습니다. 템플릿을 바꿔도 글과 주소는 그대로입니다.

## 6. 문의 관리

![문의 관리](images/ad-04-inquiries.png)

홈페이지 방문자가 남긴 **문의**를 확인·처리합니다.
- **목록**: 이름·연락처·내용·상태
- **검색**: 이름·연락처·내용
- **상태 필터**: `전체 상태` / `미확인만`
- **상태 변경**: 미확인 → **확인됨** 으로 처리
- **알림**: 새 문의가 오면 등록된 **이메일** / **카카오 알림톡**으로 알림 발송
  (SNS 설정에서 수신 설정, "이번 달 발송 현황" 확인)

## 7. SEO 설정

![SEO 설정](images/ad-05-seo.png)

검색(네이버·구글) 노출을 위한 설정입니다.
- **기본 SEO**: **메타 제목(Title)**, **메타 설명(Description)**
- **소셜 미리보기**: 카톡/페북 공유 시 보이는 이미지·문구 (실시간 미리보기 제공)
- **사이트맵**: 공개 사이트맵 URL 제공(검색엔진 제출용)
- **분석/검증 연동**: **네이버 사이트 검증 코드**, 구글 등 (서치어드바이저 발급 값 입력)
- **검색엔진 사이트 등록 가이드** 제공

![템플릿 선택](images/ad-06-templates.png)

> ✅ 템플릿을 바꿔도 **입력한 콘텐츠(섹션 내용)는 그대로 유지**됩니다.

## 10. 요금제 / 결제

![요금제 · 결제](images/ad-07-billing.png)

구독 플랜과 결제를 관리합니다.
- **플랜 보러가기 / 플랜 업그레이드**: 상위 플랜으로 변경(더 많은 기능/한도)
- **결제 수단 등록**: 카드 등록 후 정기결제
- **무료 체험**: 체험 기간 안내
- **구독 해지**: 해지해도 **현재 결제 기간까지는 계속 이용** 가능
- **구독 만료** 시 안내 페이지 표시

> 플랜에 따라 사용 가능한 기능(콘텐츠 편집·SEO·분석 등)과 한도(이미지 용량, 알림톡 수 등)가 달라집니다.

## 11. 자주 하는 작업

| 하고 싶은 것 | 경로 |
|---|---|
| 홈페이지 문구/사진 바꾸기 | 콘텐츠 편집 → 섹션 선택 (또는 홈페이지 인라인 편집) |
| 카카오·인스타 링크 걸기 | SNS 설정 |
| 새 문의 확인·처리 | 문의 관리 → 상태 변경 |
| 네이버/구글 검색 노출 | SEO 설정 → 메타 정보 + 사이트 검증 |
| 홈페이지 디자인 변경 | 템플릿 → 선택 → 적용 |
| 방문자 수 확인 | 대시보드 / 분석 |
| 플랜 변경·카드 등록 | 요금제 |
| 실제 홈페이지 보기 | 사이드바 "내 홈페이지 바로가기" |

## 12. 문제 해결

| 증상 | 확인 |
|---|---|
| 메뉴가 안 보임 | 해당 기능이 요금제/설정에 포함됐는지 확인, 필요 시 업그레이드·운영사 문의 |
