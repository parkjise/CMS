## 페이지별 상세 정의

### 메인페이지 — 홈 / 필수
- 목표: 첫인상·사업 소개·신뢰 확보·문의 전환
- 섹션: 메인 비주얼, 회사소개 요약, 주요 사업 3개, 기업 수치, 실적/고객사, 최근 소식, 문의 CTA
- CMS 필드: 비주얼(제목·설명·PC/모바일 이미지·버튼), 섹션 노출·순서, 사업 카드 연결, 실적 연결, 공지 게시판 연결
- 사용자 액션: 히어로 버튼 → 회사소개/문의; 사업 카드 → 상세; 뉴스 → 게시글
- 예외/검수: 섹션별 노출 전환·미리보기·예약 게시

### 회사개요 — 회사소개 / 필수
- 목표: 회사 기본 정보와 신뢰 정보 제시
- 섹션: 서브 비주얼/페이지 제목, 회사 소개, 핵심 수치, 사업/역량 요약, 기본 회사정보
- CMS 필드: 상단 배너, 소개 문구, 회사 사진, 설립일·대표자·업종·사업자등록번호(필요시), 주요 수치
- 사용자 액션: 사업분야/오시는 길 상세 이동
- 예외/검수: 등록되지 않은 기업 수치는 자동 숨김

### CEO 인사말 — 회사소개 / 선택
- 목표: 경영 철학·고객에 대한 약속
- 섹션: CEO 사진, 인사말 제목, 본문, 대표자명/서명
- CMS 필드: 대표자명, 대표 사진, 인사말 본문, 서명 이미지(선택)
- 사용자 액션: 회사개요 및 비전으로 연결
- 예외/검수: 대표자 사진 없으면 텍스트형 레이아웃

### 연혁 — 회사소개 / 필수
- 목표: 성장 과정과 성과 소개
- 섹션: 연도별 그룹, 월별 주요 사건, 이미지(선택)
- CMS 필드: 연도, 월, 내용, 대표 이미지, 정렬 순서
- 사용자 액션: 연도 탭/필터; 최신순·과거순 선택
- 예외/검수: 연도·항목 무제한 추가 및 순서 변경

### 비전·핵심가치 — 회사소개 / 선택
- 목표: 기업 가치와 비전의 구조화
- 섹션: 비전 타이틀, 미션, 핵심가치 카드 3~4개
- CMS 필드: 비전, 미션, 가치 제목/설명/아이콘, 배경 이미지
- 사용자 액션: 카드 자세히 보기(선택)
- 예외/검수: 핵심가치 2~6개 대응

### 조직도 — 회사소개 / 선택
- 목표: 조직 구조 안내
- 섹션: 조직도 이미지/도식, 조직·부서 안내
- CMS 필드: 조직도 이미지 또는 조직 노드, 설명, 부서명
- 사용자 액션: PC 확대/모바일 스크롤
- 예외/검수: 조직도 미등록 시 메뉴 자동 비노출 설정

### 오시는 길 — 회사소개 / 필수
- 목표: 방문과 연락 편의 확보
- 섹션: 회사 주소, 지도, 연락처, 대중교통, 주차 안내
- CMS 필드: 주소, 위도·경도 또는 지도 링크, 전화, 이메일, 교통/주차 안내
- 사용자 액션: 지도 앱 열기·전화걸기·주소 복사
- 예외/검수: 지도 API 실패 시 주소 및 외부 지도 링크 유지

### 사업소개 — 사업분야 / 필수
- 목표: 주력 사업을 쉽고 빠르게 전달
- 섹션: 사업 소개, 사업분야 카드, 프로세스·경쟁력, 문의 CTA
- CMS 필드: 사업명, 요약, 대표 이미지, 순서, 상세 연결
- 사용자 액션: 카드 → 상세/제품·서비스
- 예외/검수: 사업 개수에 따라 1~4열 자동 조정

### 제품·서비스 — 사업분야 / 필수
- 목표: 제공 제품/서비스의 탐색·문의
- 섹션: 카테고리, 검색/필터, 카드 리스트, 상세(이미지·설명·사양·첨부)
- CMS 필드: 카테고리, 명칭, 요약, 대표/상세 이미지, 특징, 사양(선택), 카탈로그 파일, 문의 버튼
- 사용자 액션: 카테고리 필터·검색·상세·자료 다운로드·문의
- 예외/검수: 가격이 없거나 비공개인 B2B 제품 지원

### 기술력·경쟁력 — 사업분야 / 선택
- 목표: 차별적 역량과 기술 설명
- 섹션: 강점 3~4개, 설비/역량, 프로세스, 관련 인증
- CMS 필드: 강점 제목, 설명, 아이콘, 사진, 수치, 순서
- 사용자 액션: 관련 제품/문의 연결
- 예외/검수: 기술 정보는 공개 가능한 항목만 노출

### 인증 및 특허 — 사업분야 / 선택
- 목표: 기업 신뢰 및 기술력 입증
- 섹션: 인증 분류, 인증서 카드, 발급기관, 발급일, 상세
- CMS 필드: 명칭, 분류, 기관, 등록번호(선택), 발급·만료일, 이미지·PDF, 공개 여부
- 사용자 액션: 분류 필터·확대·PDF 다운로드
- 예외/검수: 만료된 인증 공개 알림 및 관리자 경고

### 주요 실적 — 포트폴리오 / 필수
- 목표: 실적과 수행 규모를 빠르게 전달
- 섹션: 핵심 실적 지표, 연도별 주요 실적, 프로젝트 연결
- CMS 필드: 연도, 실적명, 수행 내용, 수치/단위, 공개 여부, 관련 프로젝트
- 사용자 액션: 연도 필터·상세 링크
- 예외/검수: 고객사 비공개 실적 익명화

### 프로젝트·납품 사례 — 포트폴리오 / 필수
- 목표: 구체적 수행 사례 소개
- 섹션: 카테고리, 프로젝트 카드, 상세(개요·과제·결과·이미지)
- CMS 필드: 제목, 분류, 진행기간, 고객사(공개 동의), 설명, 성과, 이미지, 관련 제품
- 사용자 액션: 목록 필터·상세·관련 사례
- 예외/검수: 비공개 고객사명·민감 정보 노출 방지

### 고객사·파트너 — 포트폴리오 / 선택
- 목표: 협력 네트워크 신뢰 형성
- 섹션: 고객사/파트너 로고 그리드, 제휴 소개
- CMS 필드: 기관명, 로고, URL, 분류, 정렬, 공개 동의 상태
- 사용자 액션: 로고 클릭 → 외부 링크(선택)
- 예외/검수: 로고 사용 허가와 출처 확인

### 공지사항 — 홍보센터 / 필수
- 목표: 필수 공지와 운영 정보 전달
- 섹션: 게시글 목록, 검색, 공지 고정, 상세, 첨부
- CMS 필드: 제목, 본문, 작성자 표시명, 게시일, 고정 여부, 첨부, 공개 상태
- 사용자 액션: 검색·페이지네이션·게시글 상세·파일 다운로드
- 예외/검수: 임시저장/예약/게시/숨김, 삭제 복구

### 회사소식·뉴스 — 홍보센터 / 필수
- 목표: 기업 활동과 최신 소식 공유
- 섹션: 썸네일 카드, 카테고리, 날짜, 상세
- CMS 필드: 제목, 요약, 본문, 썸네일, 카테고리, 게시일, SEO 설명
- 사용자 액션: 목록 필터·상세·공유
- 예외/검수: 게시글 썸네일 없으면 기본 이미지

### 자료실 — 홍보센터 / 선택
- 목표: 브로슈어 및 공개 자료 제공
- 섹션: 자료 목록, 분류, 파일 형식/크기, 다운로드
- CMS 필드: 제목, 설명, 분류, 첨부 파일, 언어, 공개 여부
- 사용자 액션: 검색·다운로드
- 예외/검수: 대용량 파일 제한·보안 검사

### 문의하기 — 고객지원 / 필수
- 목표: 신규 고객 문의 접수·분류·처리
- 섹션: 문의 안내, 문의 유형, 입력 폼, 개인정보 동의, 완료 상태
- CMS 필드: 문의유형, 회사명, 담당자명, 이메일, 전화(선택), 제목, 문의내용, 첨부(선택), 동의
- 사용자 액션: 유효성 검사·제출·접수번호·처리 담당자 알림
- 예외/검수: 개인정보 최소 수집·동의 기록·스팸 차단·보관/파기

### 자주 묻는 질문 — 고객지원 / 선택
- 목표: 반복 문의 감소·정보 접근 개선
- 섹션: 분류 탭, 질문·답변 아코디언, 문의 CTA
- CMS 필드: 카테고리, 질문, 답변, 정렬, 공개 상태
- 사용자 액션: 검색·아코디언 열기·문의 이동
- 예외/검수: 질문/답변 구조화 데이터는 실제 표시 내용과 일치

### 채용정보 — 고객지원 / 선택
- 목표: 채용 공고 안내 및 지원 경로 제공
- 섹션: 채용 공고 목록, 모집분야, 고용형태, 상태, 상세
- CMS 필드: 직무, 근무지, 고용형태, 기간, 상세, 지원 URL/이메일
- 사용자 액션: 상태 필터·상세·외부 지원
- 예외/검수: 마감된 공고 자동 마감 표시

## CMS 관리자 메뉴
- **대시보드**: 운영 요약, 최근 문의, 게시 대기, 최근 수정
- **사이트 관리**: 기본 정보, 도메인, SEO/AEO/GEO, 약관/정책
- **디자인 관리**: 프리셋, 색상, 폰트, 헤더/푸터, 반응형
- **메뉴 관리**: 추가/편집/삭제, 순서, 비노출, 다국어 확장
- **페이지 관리**: 페이지 생성, 템플릿, 섹션 구성, 미리보기, 게시
- **콘텐츠 관리**: 회사 정보, 연혁, 사업, 제품, 실적, 인증
- **게시판 관리**: 공지/뉴스/자료실/FAQ, 게시글, 디자인/필드, 권한
- **문의 관리**: 접수, 상태변경, 담당자, 답변 메모, 내보내기
- **미디어 관리**: 이미지/파일 업로드, 재사용, 대체텍스트
- **사용자·권한**: 관리자 역할, 페이지별 권한, 감사 로그

## 운영 정책
- 콘텐츠 상태: 초안 → 검토(선택) → 승인(선택) → 게시/예약 → 종료/비공개
- 콘텐츠 변경 이력, 권한 제어, 미리보기, 게시 취소 및 복구 제공
- 개인정보 최소 수집, 동의 이력, 보관·파기, 파일 보안, 스팸 방지
- 반응형 PC/태블릿/모바일 및 웹 접근성 검수
- SEO 메타데이터, URL 슬러그, OG 이미지, 사이트맵 제공

## MVP
- P0: 기본 5메뉴, 필수 페이지, 게시판·문의·제품·실적 CRUD, 미디어·권한·SEO
- P1: 디자인 프리셋, 예약 게시, 버전 비교, 고급 필터
- P2: 다국어, AI 글쓰기 보조, AEO/GEO 확장
