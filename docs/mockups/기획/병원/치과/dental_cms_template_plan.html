01 / Project Overview

프로젝트 개요

병원별 차별화는 유지하고, 운영 관리의 복잡성은 줄이는 치과 홈페이지 템플릿

프로젝트 목표

하나의 공통 CMS에서 치과별 로고, 색상, 의료진, 진료과목, 진료시간, 휴진, 오시는 길, 예약 채널을 관리하고 다양한 홈페이지 디자인에 적용합니다.

대상: 개인 치과의원, 중대형 치과, 분점 운영 치과, 홈페이지 제작 에이전시

핵심 사용자

환자: 진료정보 확인, 의료진·진료과목 탐색, 방문 경로 확인, 예약·상담

병원 관리자: 일정과 콘텐츠 수정, 예약 신청 관리, 의료광고 검수 및 게시

슈퍼관리자: 템플릿, 고객별 사이트, 권한, 공통 모듈 관리

03 / Design Principles

환자 경험과 운영 효율을 위한 설계 원칙

환자 측면

① 진료시간·휴진·주소·주차 정보를 한눈에 확인

② 의료진의 학력·경력·진료분야 객관적 제공

③ 진료방법·과정·주의사항을 균형 있게 설명

④ 전화·네이버 예약·자체 예약·카카오 상담에 쉽게 접근

⑤ 작은 화면에서도 읽기 쉽고 클릭하기 편리한 모바일 UI

운영·법무 측면

① 운영정보 변경 즉시 홈페이지 반영

② 콘텐츠 작성–검수–승인–게시 워크플로우

③ 허위·과장·환자경험담 등 광고 위험요소 경고

④ 개인정보 최소 수집, 권한 분리, 로그 및 파기 정책

⑤ 사이트별 자료 격리와 유지보수 가능한 공통 컴포넌트

04 / Information Architecture

홈페이지 메뉴 구조 (IA)

상단 GNB는 5~6개 상위 메뉴로 유지하고, 자주 찾는 기능은 퀵메뉴에도 연결합니다.

01. 병원 소개

  • 병원 소개·진료 철학
  • 의료진 소개
  • 의료장비·시설 안내
  • 병원 둘러보기

02. 진료 안내

  • 임플란트
  • 치아교정
  • 심미·미백
  • 충치·신경·보철
  • 잇몸치료·스케일링
  • 사랑니 등 개별 항목

03. 진료·방문 안내

  • 진료시간·진료일정
  • 휴진·공휴일 안내
  • 오시는 길
  • 주차 안내
  • 초진 환자 안내
  • 비급여 진료비 안내

04. 예약·상담

  • 온라인 예약
  • 예약 조회·취소
  • 전화 문의
  • 카카오톡 채널·챗봇
  • 자주 묻는 질문

05. 병원 소식

  • 공지사항
  • 진료 일정 변경
  • 치과 건강정보·칼럼
  • 언론 보도(선택·검수)

06. 법정·공통 정보

  • 개인정보처리방침
  • 이용약관(해당 시)
  • 비급여 정보
  • 의료기관 필수 표기
  • 환자 권리·고충 안내
CMS에서 사용하지 않는 진료과목·메뉴는 숨김 처리합니다. 복수 지점 운영 시 선택한 지점에 따라 전화번호·진료시간·주소·예약 링크·주차 안내를 함께 변경합니다.

운영정보 동기화 규칙

관리자가 임시 휴진을 등록하면 메인 진료정보 패널, 진료시간 화면, 공지/배너, 자체 예약 가능 날짜를 일관되게 갱신합니다.

네이버 예약 등 외부 예약 데이터는 공식 API·연동 계약이 허용하는 범위만 자동 반영하며, 불가능할 경우 관리자 수동 변경 알림을 제공합니다.

분류유의사항CMS 대응 정책

부작용·주의사항중요한 정보 누락이나 치료효과의 단정진료 상세 페이지에 위험·주의사항 검토 항목 제공
자격·전문분야법적으로 인정되지 않는 자격·전문의 표시 금지의료진 자격 증빙 첨부, 검수자 확인
가격·이벤트부당한 환자 유인·오인 소지가 있는 표현비용 조건, 적용 범위, 법적 검토 필수
