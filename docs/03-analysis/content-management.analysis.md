## 2. 기획과 다르게 한 것 (의도한 변경 — 기획서에 반영함)

| 항목 | 기획 | 구현 | 까닭 |
|---|---|---|---|
| 공개 API 주소 | `/contents/{type_key}` | `/content-types/{type_id}/items` | 섹션이 id 를 저장 — 키를 바꿔도 연결 유지 |
| 콘텐츠 목록 '사용 위치' 칸 | 목록 칸 | 휴지통 확인 창 · 편집 화면 아래 | 목록마다 섹션 조건 계산을 피함 |
| 카테고리 순서 | 끌기 | 위/아래 · 하위로 · 맨 위로 버튼 | 두 단계를 키보드로도 정확히 |
| 공통 블록 참조 방식 | 섹션이 블록을 가리킴 | 가리키되 값은 복사해 두고 같게 맞춤 | 홈페이지 · 미리보기 · 인라인 편집 코드를 바꾸지 않음 |
| 대표 사진 업로드 위치 | — | 게시글 사진과 같은 `board` | 업로드 위치를 새로 만들지 않음 |
