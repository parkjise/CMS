## 2. 사용자 중심 UI/UX 개선 기획안

초보 웹사이트 운영자도 매뉴얼 없이 직관적으로 사이트와 게시판을 운영할 수 있도록 **정보 구조(IA) 단순화**, **즉각적 시각 피드백**, **실수 방지 장치**를 중심으로 개선안을 제안합니다.

### 2.1 불필요한 클릭(뎁스) 줄이기 및 정보 구조(IA) 재배치

1. **게시판 관리 사이드바 11개 → 5개 핵심 메뉴로 통폐합**
   - **현황 문제**: 현재 `게시판 관리` 하위에 11개 메뉴가 나열되어 있고, 그중 `필드 관리`/`카테고리 관리`, `권한 관리`/`환경설정`은 같은 화면으로 이동해 혼란을 줍니다. 또한 `디자인`, `필드`, `설정`을 누를 때마다 임의의 게시판으로 튕겨 맥락이 끊깁니다.
   - **개선안**: 사이드바는 **① 게시판 목록(통합 허브)**, **② 전체 게시글 관리**, **③ 신고된 글**, **④ 휴지통**, **⑤ 변경 기록** 5개로 슬림화합니다.
   - 특정 게시판의 `디자인`·`필드/카테고리`·`설정`은 **게시판 목록에서 게시판을 선택하거나 상단 통합 컨텍스트 스위처(드롭다운)**를 통해 진입하고, 내부 탭(`글 관리 | 디자인 | 필드·카테고리 | 권한·설정`)으로 1뎁스 안에서 즉시 전환하도록 통일합니다. (사이드바의 `게시판 만들기`는 `게시판 목록` 우측 상단 Primary CTA 버튼 `+ 새 게시판`으로 일원화)
2. **사이트 관리 내 '검색·AI 노출' 그룹핑**
   - `SEO 설정`, `AEO 설정`, `GEO 설정`은 초보 운영자에게 용어 자체가 낯섭니다. 사이드바 라벨에 보조 설명을 툴팁으로 제공하거나 **검색·AI 최적화** 상위 탭으로 묶어 `검색엔진(SEO)` → `질문답변(AEO)` → `AI 브랜드 소개(GEO)` 흐름으로 한 화면 내 탭 전환을 지원하면 페이지 이동 대기 시간을 줄일 수 있습니다.

### 2.2 설정 변경 시 즉각적인 시각 피드백 제공

1. **SEO 사이트맵 & robots.txt 실시간 검증 패널**
   - `생성 결과 확인` 클릭 시 `다시 확인`으로 글자만 바꾸지 않고, 인라인 결과 카드로 **포함된 공개 페이지 수 / 게시판 수 / 게시글 수**, **제외된 비공개 항목 수**, **마지막 갱신 시각**을 수치로 즉시 보여줍니다.
2. **사이트 기본정보 → 실제 홈페이지 헤더·푸터 미니 프리뷰 연동**
   - 현재 하단에 `푸터 미리보기`가 제공되고 있으나 스크롤 최하단에 위치해 입력 중 변화를 바로 보기 어렵습니다. 데스크톱 기준 **우측 고정(Sticky) 미리보기 패널**을 두어 로고·파비콘·사이트명·사업자정보 토글 변경 시 헤더(탭 아이콘 포함)와 푸터의 변경 전/후 모습을 실시간으로 확인하게 합니다.
3. **게시판 설정 변경 전/후 요약(Diff) 배지**
   - 게시판 권한(`누구나` → `회원만`)이나 `검색 노출`을 변경할 때, 저장 전 확인 영역에 `"이 변경으로 인해 검색엔진 사이트맵에서 제외됩니다"`와 같은 **영향 범위 미리보기 배지**를 즉시 표시합니다.

### 2.3 실수 방지를 위한 UX 장치

1. **커스텀 이탈 방지 모달 ("저장 후 이동" 원클릭 지원)**
   - 현재 브라우저 기본 `window.confirm`("저장하지 않은 변경사항이 있습니다...")은 투박하며, 사용자가 저장하려면 취소를 누르고 다시 저장 버튼을 찾아 눌러야 합니다.
   - **개선안**: 커스텀 모달을 띄워 `[저장하고 이동]` / `[변경사항 버리고 이동]` / `[계속 편집]` 3가지 선택지를 제공합니다.
2. **구역별 저장 → 페이지 단위 통합 저장 + 미저장 섹션 인디케이터**
   - `/admin/boards/[id]/settings`처럼 4개 구역마다 저장 버튼이 흩어진 구조는 누락 사고의 주원인입니다. 페이지 하단 **고정(Sticky) 통합 저장 바**로 일원화하고, 수정된 섹션 제목 옆에만 주황색 `수정됨` 점(Dot)을 표시해 변경 범위를 명확히 인지시킵니다.
3. **위험 작업 및 즉시 생성 작업 안전장치**
   - **약관 `새 버전 만들기`**: 클릭 즉시 DB에 초안을 생성하지 말고, 편집 모드 진입 후 사용자가 `[초안 저장]` 또는 `[공개/시행 예약]`을 누를 때만 버전을 생성합니다.
   - **게시판 `휴지통으로` / `영구 삭제`**: 영구 삭제 시 게시판 이름 재입력 확인 또는 영향받는 게시글/첨부파일 수 명시 경고를 제공합니다.

### 2.4 메뉴별 `AS-IS → TO-BE` 비교 정리

| 메뉴 | AS-IS (현재 불편한 점) | TO-BE (개선 방향) |

## 3. 최신 트렌드 기반 AI 편의 기능 기획안

중소 사업자·병원·기업 등 1인 또는 소수 관리자가 반복적인 설정과 콘텐츠 작성에 들이는 시간을 대폭 줄일 수 있도록, 각 메뉴 맥락에 맞춘 실용적인 AI 보조 기능을 제안합니다.

### 3.1 사이트 기본정보 기반 SEO · GEO 메타/키워드 자동 생성

- **UI 배치 위치**: `/admin/site/seo` (`기본 SEO` 탭 상단) 및 `/admin/site/geo` (`기업 · 브랜드 정보` 섹션 우측 상단)에 **`✨ AI 자동 채우기`** 버튼 배치
- **사용자 인터랙션 흐름**:
  1. 관리자가 **`✨ 사이트 정보로 AI 추천받기`** 버튼 클릭
  2. AI가 `/admin/site/info`에 입력된 `사이트명`, `업태/종목`, `주소`, `운영시간`을 읽어 SEO 메타 제목(50~60자), 메타 설명(150~160자), 대표 키워드 5개(GEO의 경우 기업 소개 500자 & 주제 키워드 10개)를 생성해 **미리보기 드로어/모달**에 표시
  3. 관리자가 문구 톤(신뢰감/친근함/전문적)을 선택하거나 일부 수정 후 **`[한 번에 적용하기]`** 클릭 → 폼에 자동 입력(Dirty 상태 전환 후 최종 저장)
- **기대 효과**: 검색엔진 최적화(SEO)와 AI 검색 최적화(GEO) 지식이 없는 초보 운영자도 10초 만에 규격(글자 수 제한)에 맞는 고품질 메타 데이터를 완성할 수 있습니다.

### 3.2 약관 · 개인정보처리방침 업종 맞춤형 초안 생성 및 변경점 요약

- **UI 배치 위치**: `/admin/site/policies` 편집 에디터 상단 툴바 (`기본 문안으로 채우기` 옆 **`✨ 업종 맞춤 문안 다듬기`**, `변경 내용 요약` 입력칸 옆 **`✨ AI 요약 생성`**)
- **사용자 인터랙션 흐름**:
  1. `✨ 업종 맞춤 문안 다듬기` 클릭 → 수집 항목(예: 예약, 상담, 회원 가입, 게시판 글쓰기) 체크박스 선택 후 생성 요청
  2. AI가 기본 문안에서 불필요한 조항을 정리하고 사업자 정보(상호·대표자·개인정보 보호책임자·이메일)를 자동 치환한 결과 미리보기 제공
  3. 버전 저장 전 **`✨ AI 요약 생성`** 클릭 시 이전 버전 대비 달라진 조항을 1~2줄로 자동 요약해 `변경 내용 요약` 필드에 채움
- **기대 효과**: 법적 필수 기재 사항 누락을 줄이고, 방문자 동의 이력에 남는 버전별 변경 사유를 일관되고 정확하게 기록할 수 있습니다.

### 3.3 게시판 목적별 원클릭 AI 세팅 어시스턴트

- **UI 배치 위치**: `/admin/boards/new` 1단계 상단 배너 (**`✨ AI로 게시판 한 번에 구성하기`**) 및 `/admin/boards/[id]/fields` 상단 (**`✨ 목적에 맞는 필드·카테고리 추천`**)
- **사용자 인터랙션 흐름**:
  1. 관리자가 자연어로 목적 입력 (예: *"피부과 시술 전후 후기 게시판, 별점이랑 시술 부위 카테고리가 필요해"*)
  2. AI가 5단계 위저드 전체 설정을 추천 패키지로 미리보기 제시:
     - **유형**: `리뷰형(★★★★★)`
     - **사용자 정의 필드**: `시술 부위(선택형)`, `담당 원장(짧은 글)`
     - **카테고리**: `리프팅`, `레이저`, `스킨케어`
     - **권한·운영**: `읽기: 누구나 / 쓰기: 회원만 / 비밀글 허용`
  3. **`[이 구성으로 적용]`** 클릭 시 위저드 2~4단계 값이 자동 채워지며 최종 검토(5단계)로 바로 이동
- **기대 효과**: 5단계 위저드와 필드·카테고리·권한 메뉴를 오가며 설정하는 피로도를 획기적으로 줄이고, 초보자가 가장 많이 실수하는 권한(예: 후기 게시판인데 비회원 쓰기 허용 등) 오류를 예방합니다.

### 3.4 공지사항 · FAQ 초안 작성 및 다국어 자동 번역

- **UI 배치 위치**: `/admin/boards/[id]/posts` 글쓰기 에디터 상단 툴바 (**`✨ AI 글쓰기 도우미`**, **`🌐 다국어 번역`**) 및 `/admin/site/aeo` 연동 FAQ 관리 영역
- **사용자 인터랙션 흐름**:
  1. 관리자가 핵심 메모만 입력 (예: *"추석 연휴 9/14~9/18 휴진, 응급 문의는 카카오 채널"*) 후 **`✨ 공지 초안 생성`** 클릭
  2. 제목 후보 3개와 정중한 본문 초안, AEO(질문-답변)용 요약 쌍을 미리보기로 출력
  3. **`[본문에 적용]`** 클릭 후 필요 시 **`🌐 영문/일문/중문 번역`** 선택으로 다국어 공지 병기 또는 별도 글 생성
- **기대 효과**: 휴무일 안내, 이벤트 공지, FAQ 답변 작성에 드는 시간을 80% 이상 단축하고, 외국인 방문객 대응 품질을 높입니다.

### 3.5 신고된 글 · 스팸 게시글 AI 사전 요약 및 조치 추천

- **UI 배치 위치**: `/admin/posts/reports` 신고 목록 각 행 우측 및 상세 모달 (**`✨ AI 유해성 분석 요약`**)
- **사용자 인터랙션 흐름**:
  1. 신고가 누적된 글 목록 진입 시 AI가 신고 사유와 본문 문맥을 분석해 **유형 배지(`광고/스팸 의심`, `욕설/비방`, `단순 오신고 가능성`)**를 자동 표시
  2. 행 클릭 시 원문 전체를 읽지 않아도 AI가 문제 문장을 하이라이트하고 **`[비공개 유지 추천]`** 또는 **`[정상 글 복구 추천]`** 액션 제안
  3. 관리자가 추천 버튼 클릭 시 즉시 상태 반영 및 처리 이력 기록
- **기대 효과**: 관리자가 악성·스팸 글 전문을 일일이 읽는 감정적 피로도를 줄이고, 오신고로 자동 숨김 처리된 정상 게시물을 빠르게 구제할 수 있습니다.
