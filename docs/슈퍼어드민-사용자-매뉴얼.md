# 슈퍼 어드민(운영자) 사용자 매뉴얼

> **대상:** 운영사(플랫폼 운영자) 전용 관리 페이지
> **접속 주소:** 프로덕션 `https://system.{도메인}` / 로컬 개발 `http://localhost:3002`
> **주의:** 이 페이지는 운영사 직원 전용입니다. **모든 쓰기 작업은 감사 로그(audit log)에 자동 기록**됩니다.

---

## 1. 로그인 / 로그아웃

1. 접속하면 **운영자 전용 로그인** 화면이 표시됩니다.
2. **이메일**과 **비밀번호**를 입력하고 로그인합니다.
   - 잘못 입력 시: "이메일 또는 비밀번호가 올바르지 않습니다." 안내
   - 슈퍼 어드민 계정은 보안을 위해 **2단계 인증(2FA)** 및 짧은 세션(기본 5분)이 적용될 수 있습니다.
3. 로그인 후 자동으로 **대시보드**로 이동합니다.
4. 로그아웃: 좌측 하단(또는 상단) **로그아웃** 클릭.

> 보안: 슈퍼 어드민 API는 IP 화이트리스트가 적용될 수 있어, 허용되지 않은 IP에서는 접근이 차단됩니다(운영 설정에 따름).

---

## 2. 화면 구성 (좌측 메뉴)

| 메뉴 | 설명 |
|---|---|
| **대시보드** | 전체 테넌트 현황 · 핵심 지표(KPI) |
| **테넌트 관리** | 사업체(테넌트) 목록·생성·상세 관리 |
| **기능 배포** | 기능 플래그를 테넌트에 배포/회수 |
| **공지 관리** | 테넌트 대상 공지 작성·발송 |
| **모니터링** | 시스템 상태·에러·알림 사용량 |
| **수익 관리** | MRR 등 매출 지표 |
| **결제 현황** | 플랜별 분포·연체 테넌트 |

---

## 3. 대시보드 (SA-01)

로그인 직후 보이는 운영 현황 화면입니다.

**핵심 지표(KPI) 카드**
- **전체 테넌트**: 가입된 사업체 수
- **이번달 MRR**: 월 반복 매출
- **이번달 AI 사용**: AI 기능 사용량
- **이번달 알림톡**: 카카오 알림톡 발송량

**하단 위젯**
- **플랜별 현황**: 플랜(BASIC/STANDARD/PREMIUM 등)별 테넌트 분포
- **최근 신규 테넌트**: 최근 가입한 사업체
- **만료 예정 테넌트**: 곧 플랜이 만료되는 테넌트 (선제 대응용)
- **시스템 상태**: 서버/서비스 상태 표시

> 데이터가 없으면 "데이터 없음" 등으로 표시됩니다.

---

## 4. 테넌트 관리

플랫폼에 입점한 **사업체(테넌트)** 를 관리합니다.

### 4-1. 목록 보기 / 검색 / 필터
- 표시 항목: **사업체명 · 상태(활성/비활성) · 플랜 · 템플릿 · 가입일**
- **검색**: "이름 또는 slug 검색" 입력창
- **필터**: `전체 상태`(활성/비활성), `전체 플랜`

### 4-2. 신규 테넌트 생성
1. **신규 테넌트 생성** 버튼 클릭
2. 입력 항목:
   - **사업체명**
   - **slug** — 홈페이지 주소에 쓰이는 식별자 (**영문 소문자·숫자·하이픈**만)
   - **관리자 이메일** — 테넌트 관리자 로그인 계정
   - **관리자 초기 비밀번호**
3. 생성하면 해당 사업체와 관리자 계정이 만들어집니다.

> ⚠️ 생성/수정 등 **모든 행위가 감사 로그에 기록**됩니다.

### 4-3. 테넌트 상세 (목록에서 사업체 클릭)
탭으로 구성됩니다.
- **기본정보**: 사업체명·slug·플랜·상태 등
- **기능 관리**: 이 테넌트에 개별 기능 on/off
- **사용 현황**: AI·알림톡 등 사용량
- **히스토리**: 플랜 변경 등 변경 이력
- **관리자 페이지로 접속**: 해당 테넌트의 관리자 화면으로 대리 접속(지원용)

---

## 5. 기능 배포 관리

특정 기능을 **어떤 테넌트에게 제공할지** 제어합니다 (기능 플래그).

- **기능 목록**: 등록된 기능들. 없으면 "등록된 기능이 없습니다."
- **배포 방식** 선택:
  - **전체** — 모든 테넌트
  - **플랜 기반** — 특정 플랜 이상
  - **선택** — 테넌트 검색 후 개별 지정
- **메뉴 노출 설정**: 메뉴 경로 · 메뉴 라벨 · 메뉴 아이콘 (관리자 페이지에 어떻게 보일지)
- **테넌트 알림**: 배포 시 대상 테넌트에게 **카카오 알림톡** 발송(이메일 발송은 준비 중)
- **관리자 페이지 공지 노출**: 관리자 화면에 배너로 안내
- **배포 이력 / 롤백**: 과거 배포 내역 확인 및 **롤백**(회수) 가능

> 활용 예: 신기능을 PREMIUM 플랜에만 먼저 배포 → 이력에서 확인 → 문제 시 롤백.

---

## 6. 공지 관리 (SA-05)

테넌트(관리자)에게 보내는 **공지·알림**을 작성·발송합니다.

1. **공지 작성** 클릭
2. 입력: **제목 · 유형 · 대상**
   - **대상**: 전체 / 특정 플랜 / 선택 테넌트(테넌트 검색)
3. 발송 채널:
   - **관리자 페이지 배너 노출** — 관리자 화면 상단 배너
   - **카카오 알림톡 발송** (이메일 발송은 준비 중)
4. **임시저장** 후 나중에 발송하거나, 바로 발송
5. 목록에서 기존 공지 **삭제** 가능

---

## 7. 모니터링

시스템 운영 상태를 확인합니다.
- **이번달 알림톡** 사용량
- **서버 에러** 현황 및 **최근 에러** 목록 (없으면 "최근 에러가 없습니다.")

> 상세 지표(응답시간 P95·에러율·DB 연결·큐)는 Grafana 대시보드에서도 확인할 수 있습니다.
> (운영: `docs/작업확인-매뉴얼.md`의 모니터링 스택 참고)

---

## 8. 수익 관리

매출 지표를 확인합니다.
- **MRR**(월 반복 매출) 등 수익 데이터
- **만료 예정 테넌트** — 갱신 유도/영업 대상

---

## 9. 결제 현황

결제·구독 상태를 확인합니다.
- **플랜별 분포** — 플랜별 구독 현황
- **연체 테넌트** — 결제 실패/연체 목록 (없으면 "연체 테넌트가 없습니다.")

> 연체 테넌트는 후속 조치(안내·정지 등) 대상입니다.

---

## 10. 자주 하는 작업 (빠른 흐름)

| 하고 싶은 것 | 경로 |
|---|---|
| 새 고객사 입점 | 테넌트 관리 → 신규 테넌트 생성 |
| 특정 고객 플랜/기능 조정 | 테넌트 관리 → 사업체 클릭 → 기능 관리 |
| 신기능을 일부 플랜에만 오픈 | 기능 배포 → 배포 방식(플랜 기반) |
| 전체 공지 발송 | 공지 관리 → 공지 작성 → 대상(전체) |
| 만료 임박 고객 관리 | 대시보드/수익 관리 → 만료 예정 테넌트 |
| 연체 고객 확인 | 결제 현황 → 연체 테넌트 |
| 고객 화면 직접 확인 | 테넌트 상세 → 관리자 페이지로 접속 |

---

## 11. 참고 / 주의사항

- **감사 로그**: 슈퍼 어드민의 모든 쓰기 작업(생성·수정·배포·발송 등)은 자동 기록됩니다.
- **권한 분리**: 이 페이지는 운영사 전용(`system.` 서브도메인)이며, 고객 관리자 페이지(`admin.`)와 완전히 분리되어 있습니다.
- **"준비 중" 표기**: 이메일 발송 등 일부 채널은 준비 중입니다(카카오 알림톡 우선 제공).
- 화면에 "불러오는 중…" 또는 "불러오지 못했습니다." 표시 시 잠시 후 새로고침하거나 네트워크/서버 상태를 확인하세요.
